# Breakout Game

A simple Breakout-style game built with Java Swing. Move the paddle, bounce the ball, and break all the bricks. You have 3 lives.

## Controls

| Key | Action |
|-----|--------|
| Left Arrow / A | Move paddle left |
| Right Arrow / D | Move paddle right |
| R | Restart (after game over or win) |

## Run it

You need the Java JDK (version 8 or newer) installed.

```
cd src
javac BreakoutGame.java
java BreakoutGame
```
